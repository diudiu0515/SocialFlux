# Question-scoped annotation and restored Seedance media

New sessions use scenario flow version 3: public background, sequential question review and answer, answer comparison, then state review. The server returns only the active question and its explicitly bound dialogue/video review tasks during answering. Each question is locked before the next is exposed. Shared material reviews are locked and reused. Future answers, unrelated reviews and edits to locked answers are rejected.

Normal review choices are unchecked checkboxes. Alternative judgments and required explanations remain available. Empty public-event lists mean no additional public event was recorded; absent fields are labeled as missing rather than invented.

The active release is `annotation400-seedance-public-context-20261024-v1`. It preserves the current public question text and hashes while restoring the verified 2026-10-23 Seedance assets: 100 videos for 300 T1/T3 questions, with 100 T2 questions remaining text-only. The previous deployment had reverted to local checkpoint assets. Existing generated prompt files and video hashes were verified; no paid generation was performed. The previously approved pilot remains distinguished from other assets awaiting human review.

Old dataset bundles and version 2 sessions remain recoverable with their original materials. The release banner offers “保存并进入新版入口”; it preserves the old record and lets the participant start a separate new session. Do not silently migrate old answers to new videos. Repeated scene exposure remains marked by the existing participant/assignment checks.

The private release builder is `scripts/build_annotation_seedance_release.py`. Run it against the frozen public-context source bundle and the verified Seedance generation archive, with a new output directory. Its outputs include compressed current and historical release deltas, the appended Gate2 registry, media copies and an audit manifest. These artifacts belong on the private backend; they must not enter `pages/` or the public repository.

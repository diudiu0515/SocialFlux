# 人工审核与人工测试任务汇总

更新日期：2026-10-22。可直接在本文件修改、补充或勾选。

范围包括：T1–T3 的人工测试与 GT、scenario 和 rollout 审核、Gate2 环境有效性、T4 轨迹评分与 video trigger、音视频素材质量，以及分歧裁决和正式准入。**人工测试回答“人在公开信息下做得怎么样”；GT 审核回答“结合合法证据，题目答案和质量是否可靠”。两类记录必须分开。**

## 1 任务总览

| 人工任务 | 主要看什么 | 应留下什么 |
|---|---|---|
| T1–T3 人工测试 | 与被测模型相同条件下的公开材料和选项 | 原始盲答、把握程度、接触声明、分配条件 |
| T1–T3 GT 构建 | 题目、私有状态、历史、A/B 回放或行动分支 | 最终答案、可接受选项、题目质量、证据与理由 |
| Scenario 审核 | 背景、角色、目标、约束、历史和初始状态是否合理 | 场景判断、修改意见；正式 Gate1 另需冻结签署 |
| Rollout 审核 | 对话、角色、状态变化及互动发展是否合理 | 逐轨迹判断、问题轮次；正式 Gate3 另需质量审核 |
| Gate2 专项 | 状态更新、干预、稳健性、视频表达和时间尺度 | 独立判断、专项评分或合理性判断、证据 |
| T4 人工评分 | 既有轨迹在五个维度上的表现 | 每维分数、引用轮次、理由；锁定后与机器评分比较 |
| T4 trigger 与视频审核 | 哪些位置应触发、何时触发、实际视频是否对应 | 误触发、漏触发、时机、频率、视频匹配及缺失记录 |
| 音视频质量审核 | 台词、口型、表情、身份、音轨、情境和播放 | 每片段可用性、问题类别、时间点和修改建议 |
| 共识与裁决 | 不同人的答案、质量判断或评分分歧 | 共识标签、第三人裁决及其依据、未解决问题 |

## 2 T1–T3 人工测试

这里指真人作为被测者独立答题，用于人类基线，不是审核模型答案。

- [ ] 按固定场景组和模态领取任务，确认匿名编号与真实参与者一一对应。
- [ ] 如实声明是否看过同场景、参考答案、私有状态或其他版本材料。
- [ ] 只看分配条件允许的公开材料；文字与音视频条件不能在中途自行切换。
- [ ] 独立选择答案并填写把握程度；记录题意不清、多个选项合理或材料不足等问题。
- [ ] 整组盲答完成后锁定，之后的 GT 核对不能覆盖原答案。
- [ ] 同一参与者重复看同一场景、跨版本或跨模态再次作答时，保留接触记录，不重复计为首次独立测试。
- [ ] 计算该参与者准确率时排除其本人的 GT；需要至少两名其他审核人的一致标签，缺少独立 GT 时保持未定。

测试结果应按 T1/T2/T3、模态及普通/Hard 分别汇总，报告有效人数、题数、覆盖和排除原因。文字与音视频比较需要控制同场景的先前接触。

**待确认的扩展**：是否还需要真人扮演行动角色，与环境实际进行 T4 在线互动。对已有轨迹打分不等于真人参加在线 T4；若增加，需要另定人类任务入口、信息条件、轮次预算和评分方案。

## 3 T1–T3 GT 构建

### 逐题共通检查

- [ ] 题目对象、时间点、任务定义和证据范围明确。
- [ ] 题干与选项能理解，没有明显措辞捷径、答案泄漏或不必要的歧义。
- [ ] 公开材料足以支持所要求的判断；不能仅凭私有答案存在，就认定题目可回答。
- [ ] 对照相关私有状态、历史或分支，给出主答案及可接受选项。
- [ ] 检查机器候选及其理由，允许修改或否定机器答案。
- [ ] 选择“可用／需修改／剔除”，写明具体证据、问题与修改建议。
- [ ] 多个合理答案不能标为“唯一最佳答案可用”；无可靠答案时明确记录。
- [ ] 检查普通/Hard 设计是否符合实际推理要求；技术故障或材料缺失不能充当难度。

### 各任务重点

| 任务 | 人工重点 |
|---|---|
| T1 状态理解 | 判断环境角色而非行动模型；区分情绪、行动倾向、关系与风险；核对当前状态与变化方向；只能使用截止点内证据，不能用未来结果倒推。 |
| T2 历史依赖 | A/B 角色、背景和已成立事实一致，改写历史自然且有因果意义；共同结尾的台词、画面和音频相同；两条历史各有对应状态与回放证据，不能把 A 的状态套给 B。 |
| T3 后果预测 | 候选行动具有真实取舍；分支起点与外部条件一致；即时和延迟窗口匹配题意；检查跨维后果；单条分支不能证明普遍概率或必然结果。 |

### 独立判断与共识

1. 先保存、锁定整组公开材料盲答。
2. 有独立环境判断任务时，先完成并锁定，再开放机器结果。
3. 查看合法私有证据，形成 GT 判断；“未看机器建议的 GT 初判”和“机器辅助后的最终审核”若都要采集，应分阶段保存。
4. 至少两名不同审核人独立审核同一组；一致形成共识候选，分歧或质量问题交第三人裁决。
5. 保留原盲答、各人判断、机器候选、最终裁决和版本，不能只留下最后一个答案。

**当前流程差异**：本地 `/offline-annotation` 有独立 GT 初判再开放机器建议的阶段；托管研究版目前在 GT 阶段提供私有证据和机器答案，没有单独的整组 GT 初判锁定阶段。是否统一为更严格的两阶段 GT 流程，列入第 9 节待确认项。

## 4 Scenario 与 rollout 合理性

在 annotation 的“场景与 rollout 核对”中，同一场景的判断只填写一次，并与相关题目关联。

**Scenario**

- [ ] 背景、人物、动机、角色目标、权力关系和信息不对称相互一致。
- [ ] 约束与冲突可信，存在真实取舍和多种合理策略，不是唯一正确回应的剧本。
- [ ] 历史确实会改变后续行动的社会含义。
- [ ] 初始状态的变量、方向和强度有依据，没有预设标准答案或某策略的效果。
- [ ] 公开与私有信息边界清楚，公开材料没有泄漏隐藏状态或未来。

**Rollout**

- [ ] 对话逻辑连贯，角色行为、人格和目标前后一致。
- [ ] 回应利用相关历史，能对实际行动作出相应反应。
- [ ] 状态变化的方向、幅度和速度合理，与回复及可观察表达一致。
- [ ] 互动有推进，没有机械重复、循环、突兀结束、严重矛盾或无依据的状态震荡。
- [ ] 结束原因与过程相符；自然结束不自动等于成功，轮数上限也不自动等于失败。
- [ ] 问题注明具体轮次与依据；部分或失败轨迹明确标注，不能当完整轨迹验收。

这里的场景核对、Gate2 E2 环境评价和 Gate3 来源轨迹准入目的不同；可以关联同一证据，不能直接互相代替。

## 5 Gate2 环境专项

按固定分配材料核对；不是每个场景都必须有全部 E1–E9。样本量和正式阈值以当前批次 manifest 与 Gate 合同为准。

| 专项 | 人工需要判断什么 | 记录与顺序 |
|---|---|---|
| E1 状态更新 | 给定人格、历史、当前状态与行动，变量应上升、不变还是下降 | 先独立判断，再与环境实际更新比较。 |
| E2 完整轨迹 | 人格一致性、历史敏感性、状态连续性、回应与状态一致性、整体合理性 | 五项 1–5 分及证据；与 T4 的五维 0–10 分不同。 |
| E3 历史干预 | 去除关键历史后，变化或不变是否有因果依据 | 核对其他条件固定，并解释差异是否来自历史。 |
| E4 释义稳健性 | 两种说法是否保持事实、承诺、立场、语气强度和含义 | 先独立判断释义等价性，再看环境输出差异。 |
| E5 行动反事实 | 同一节点的不同合理行动，是否带来社会意义上合理的不同后果 | 核对共同起点与控制条件，不能只看数值“有差异”。 |
| E6 骨干敏感性 | 不同环境模型的结论是否稳健、差异如何解释 | 当前合同不强制人工签署；可人工判读异常，不能冒充已做人工实验。 |
| E7 人格干预 | 固定历史、状态和行动后，输出差异是否符合人格差异 | 核对只改变规定人格字段，说明因果合理性。 |
| E8 状态与视频 | 可见表达、人物和事件是否与节点一致，有无额外事实或私有信息泄漏 | 实际观看并听音轨，不能只凭抽帧或机器检查通过。 |
| E9 时间尺度 | 快／中／慢变量的变化速度与方向是否合理 | 检查真实变化，不能把大量不变当作稳健。 |

S0 替换、固定 S0／移除更新提示等补充消融，可另做人工机制判读；记录控制是否成立、行为变化是否合理。它们不替代正式 E1–E9。

## 6 T4 人工评分与 video trigger

### 独立轨迹评分

阅读指定证据下的完整轨迹，先独立评分，再查看 Claude 等机器评分。

| 维度 | 核心问题 |
|---|---|
| 目标达成 | 在真实约束与取舍下，角色目标实际实现了多少？区分提议、承诺和已完成结果。 |
| 状态适应 | 是否依据当时可观察的反馈调整行动？不能要求行动者知道隐藏状态。 |
| 风险管理 | 是否识别和处理冲突、失约、权限及失败风险？ |
| 挫折恢复 | 出现误解、受挫或冲突且有修复机会时，是否有效修复？ |
| 关系结果 | 相比开始，信任、尊重、边界和继续合作条件如何？ |

- [ ] 每维给 0–10 整数分、1–3 个证据轮次和理由。
- [ ] 仅恢复维度可在没有挫折及修复机会时选不适用，并解释原因。
- [ ] 礼貌、低冲突、长篇回答或自然结束不自动获得高分。
- [ ] 锁定评分后再核对私有状态、trigger 和视频，避免改写独立文字评分。
- [ ] 汇总人工与机器分数的偏差、MAE/RMSE 和分歧；缺失评分不填零。

### Trigger 合理性

- [ ] 逐轮查看触发与未触发位置，而不是只审已生成的视频。
- [ ] 是否有不应触发却触发的节点？记录误触发轮次与理由。
- [ ] 是否有应该触发却没有触发的轮次？记录漏触发及依据。
- [ ] 触发是否偏早、偏晚，频率是否过多、重复或不足？
- [ ] 触发类型和表达强度是否符合当轮情境、状态变化与公开线索？
- [ ] 对应片段是否属于同一场景、轨迹、轮次、人物和事件？
- [ ] 区分“无触发”“触发后未生成”“生成后未送达”“有文件但无法核验”；缺片不能判作视频合格。

**分别记录三件事**：触发策略是否合理、实际素材质量如何、被测模型是否真的收到视频。给文字轨迹补充审核用视频，不代表原文字条件的行动模型看过视频。

## 7 音视频素材逐片段审核

覆盖实际发布使用的片段；同一个内容哈希的片段可只审一次，但保留其所有题目和节点绑定。

- [ ] 完整播放并听完；区分仅看画面、仅看部分、听不到和无法播放。
- [ ] 英文台词与应说文本一致，没有漏句、增句、截断或关键数字／否定词错误。
- [ ] 无对白素材没有额外台词；声音与预期表达一致、清楚且无异常。
- [ ] 口型与发声／静默一致，音画没有明显错位。
- [ ] 表情、视线、动作自然，符合公开线索与情境。
- [ ] 同场景人物身份、外观和时间连续性一致；没有参考时记录无法判断。
- [ ] 不添加改变题意的事实、字幕答案、私有状态或未来线索。
- [ ] T2 的共同结尾在 A/B 两侧保持相同；T1/T3 的视频范围与题目证据窗口一致。
- [ ] 给出“可用／需修订／不可用／无法判断”，附视频时间点、问题与建议。

自动 ASR、哈希绑定和口型筛查是审核材料。正式人工结论仍需实际听看后填写。

## 8 来源准入与人工记录

### 正式来源审核

| Gate | 需要另外保留的人工工作 |
|---|---|
| Gate1 | 全场景来源、原创性与六维质量评分；逐项确认 S0 并对精确版本签署冻结。Runtime dynamics seed 由机器合同校验，不另设人工冻结。 |
| Gate3 | 唯一自然轨迹的连贯性、历史依赖、人物一致性、状态与回应一致性、互动推进、自然性六维审核；检查 hard reject。主审覆盖全部，并做 20% 确定性独立审计及边界／拒绝项复核。 |
| Gate4 | 每种 T1/T2/T3 任务的同一确定性 10% 样本，至少 2 题，由两人独立审核；分歧交第三人裁决。核对泄漏、可回答性、证据和机器候选。 |

Gate4 抽查后的 `audited-machine` 与逐题多人人工共识 GT 应明确区分来源。任务 GT 完成也不自动补齐 Gate1–3 的准入。

### 每份记录应能追溯

审核人编号、对象 ID、任务／场景／轨迹／媒体版本或哈希、分配模态、材料接触情况、独立判断、最终判断、证据轮次或视频时间点、理由、审核时间、锁定／提交状态、分歧与裁决。

缺失、无法判断、不适用、需修改和拒绝应分别记录。匿名编号用于实际身份映射，不能把同一人的多个编号算成多人一致。

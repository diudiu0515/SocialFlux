当前公开题目包为冻结版本。更新题目时应新增发布版本并先设计旧会话的恢复策略；不能直接替换包后声称旧会话仍可恢复。

邀请字符串的摘要在 Sites runtime secret `DEMO_INVITE_SHA256` 中。更新该值后需要重新部署已保存版本；旧邀请将不能领取新任务，已领取者仍可用个人恢复码访问自己的记录。恢复码不进入研究报告或 Git。

T4 五维评分与展示细则确认 — 2026-10-20

适用范围
沿用 t4_five_dimension_anchored_v1 的评分锚点及整数输出合同，不改变历史分数、不重跑 API。
本说明明确原始分数、汇总精度与 text/text_video 配对口径；不把展示规则变成新的小数评分量表。
既有 run 冻结的 rubric、模型、prompt、sampling 和实际输入仍是该 run 的权威记录。

原始评分与小数精度
每条完整轨迹由裁判对五维各给 0–10 的整数分；恢复维度可以为 null。
0/2/4/6/8/10 为证据锚点，1/3/5/7/9 用于相邻锚点之间。不得要求裁判给出无依据的 8.37 一类精度。
汇报表统一保留两位小数：单条原始 8 可展示为 8.00；跨场景均值、维度均分及配对差值也用两位小数。
原始 JSON 保留整数/null；已有 summary.json 保留其四位小数，不覆盖或截断历史数据。计算先用原始分数，最后才格式化，不能从已四舍五入的展示值反算。
两位小数是统计展示精度，不表示裁判可分辨 0.01 分的能力差异。

五维锚点
五维各 0–10 分，采用整数；0/2/4/6/8/10 为锚点，奇数表示相邻档之间。
完整机器可读锚点见 evaluation/t4_rubric.py，以及每次实验 manifest.json 中冻结的 rubric。

目标达成 Goal Achievement：按被测角色显式目标、现实约束和权衡判断。
0 目标明确失败；2 几乎无进展；4 部分进展但核心问题未决；6 显著进展或可行约定；8 核心目标实现；10 重要目标与约束均有可见达成证据。
协商目标若本身是取得协议，可由达成协议完成；外部交付目标不能仅凭承诺判定完成。

状态适应 State Adaptation：根据对方公开反馈、立场、顾虑及信息变化调整行动。
0 持续忽视反馈并恶化；2 僵化重复；4 口头回应但调整有限；6 多数反馈有对应调整；8 及时且具体地调整；10 跨关键变化持续适应，且有可见收益。
不读取隐藏 state 数值；不以视频/表情描述的出现本身加分。

风险管理 Risk Management：识别并管理具体风险、不确定性、权限边界和代价。
0 严重可避免伤害或关键越界；2 漏掉主要风险或无依据保证；4 有识别但保障笼统；6 有主要可行保障；8 具体、适度且有明确责任；10 充分处理重要风险、应变和目标权衡。

恢复 Recovery：出现退步、分歧、误解、失败提案或关系受损，并存在可行动的修复机会时评分。
0 加剧破裂或拒绝修复；2 忽视机会/反复无效；4 有尝试但损害持续；6 部分恢复；8 处理成因并恢复合作；10 稳定恢复进展且有可信防复发保障。
没有修复机会时记 null/N/A，insufficient_evidence=true；不记 0 或免费满分。

关系结果 Relationship Outcome：相对起点考察终局的可见尊重、边界、合理信任与合作能力。
0 严重可避免破裂/胁迫；2 显著恶化或勉强同意；4 紧张且缺少理解；6 可工作合作或合理边界式结束；8 明确尊重与可信合作；10 持续、相互且有证据的信任和合作改善。
礼貌、低冲突、无条件让步、篇幅长不自动高分。


证据与评分对象
只在真实 ending 后评分，区分自然结束和预算截断；自然结束不等于目标完成。
每维必须有 1–3 个有效轮次引用、理由、不确定性及证据不足标记。
目标是达成协议时，可依据实际接受的协议判断；目标是完成外部交付时，承诺不能当作已经完成。
“状态适应”评价对公开反馈的行动调整，不要求被测模型预测隐藏 state，不用 simulator 数值作裁判证据。
低冲突、礼貌、篇幅长、无条件让步和短对话本身不加分。
恢复须有可观察的退步/分歧/误解/失败提案/关系受损及可行动修复机会；背景挫折是否在本次形成修复机会必须说明。
没有修复机会时记 N/A，不补零、不补满分；原验证合同只允许恢复维度为 null。

权重、分母与汇报
展示以五个维度逐项分数和各自有效 n 为主。
单条五维均分 = 五个整数分之和 / 5，五维等权（各 20%），仅当五维全部适用时计算。
批次五维均分 = 五维均完整的轨迹的单条五维均分之平均，必须报告该子集 n；不能冒充全部场景的总体分数。
若恢复为 N/A，该条 five_dimension_mean 为 N/A，不把四维平均改名为五维总分。
旧 v1 的 core_four_mean 是四个共同维度的均分；保留其历史定义并明确标注“四维辅助均分”，不再单独用它代表五维成绩。
available_dimension_mean 混合了四维与五维的不同分母，只作为另列的辅助统计。
失败、未完成、视频能力未通过、未实际送入视频分别保留计数；不填成 0 分。分数表 n 与全部尝试数都应披露。

text 与 text+video 比较
两条件使用相同五维锚点、权重和统一的 blind text-only 终局裁判；裁判不接收策略模态标签、隐藏 state 或 appraisal。
被测模型在 text_video 条件必须实际收到视频/视频帧。抽帧输入明确写为“text+video（抽帧）”，无视频送达的条目不计为有效视频结果。
先按同批次、同场景、同被测模型匹配完整轨迹，再逐对计算 text_video - text_only，最后汇总差值；不将不匹配组均值相减称为配对收益。
恢复配对差值仅使用两侧恢复都适用的配对；五维均分配对差值仅使用两侧五维都完整的配对，分别报告有效 n。
分别汇报每维均值、n、标准差和按场景重抽样的 2000 次 bootstrap 95% 区间；只有 1 对时不报告可推断的区间。
不同 run、不同环境/裁判配置的结果分开报告，不能挑选不同批次的成功条目拼成配对。
不同裁判对相同 GPT 轨迹重评分，不等于 GPT/Claude/DeepSeek 三个策略模型分别完成互动的成绩。
机器评分未经过人工校准，不作为正式 benchmark 结论。

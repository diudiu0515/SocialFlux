# SocialFlux 50 场景任务模型对照与 Scale300 v3 构建

日期：2026-09-17

## 结论

在同一批 50 个公开任务实例上比较 Qwen3.8-Max、DeepSeek-V4-Pro-0813
和 MiniMax-M3 后，当前采用以下分工：

| 环节 | 采用模型 | 主要依据 |
| --- | --- | --- |
| T1 答案 | MiniMax-M3 | 50/50 结构通过；相对保存的确定性私有状态，粗粒度方向与强度诊断优于另外两者，且速度快 |
| T2 答案 | DeepSeek-V4-Pro-0813 | 50/50 通过；另外两者主要失败于把 evaluated agent 的话误引成目标角色证据 |
| T3 候选行动 | Qwen3.8-Max | 50/50 通过；行动差异明确，较少无依据补充精确金额、日期或制度 |
| T3 影响答案 | DeepSeek-V4-Pro-0813 | 50/50 通过；代表样本中比另外两者更能区分不同行动 |
| T4 整段评价 | Qwen3.8-Max | 50/50、零重试；能识别可观察的恶化与修复机会，速度明显快于 DeepSeek |

这些结论只用于当前构造路线，不是模型的一般排行榜。

## 对照设计

- 样本：50 个场景，覆盖 44 种冲突结构。
- 来源：33 个影视叙事改编，17 个原创。
- 长度：11 个 6–9 轮、23 个 10–14 轮、16 个 15–20 轮。
- 轨迹状态：39 个 accepted，11 个 short natural。
- 每个模型分别完成 T1、T2、T3 行动生成、T3 答案、T4，共 750 个逻辑样本。
- 实际请求：819 次，包含结构重试。
- 输入只包含获授权的虚构场景公开历史和任务题面。

## 结构通过结果

| 环节 | DeepSeek | MiniMax | Qwen |
| --- | ---: | ---: | ---: |
| T1 | 50/50，52 请求 | 50/50，52 请求 | 50/50，64 请求 |
| T2 | 50/50，51 请求 | 35/50，72 请求 | 39/50，66 请求 |
| T3 行动 | 50/50，50 请求 | 50/50，52 请求 | 50/50，50 请求 |
| T3 答案 | 50/50，50 请求 | 49/50，55 请求 | 50/50，51 请求 |
| T4 | 50/50，52 请求 | 50/50，52 请求 | 50/50，50 请求 |

T1 的私有状态比较只是一项 silver diagnostic：模拟器确定性状态不是人工 GT。
T3 尚未完成共享外部条件下的反事实分支模拟，因此模型答案仍是待人工判断的候选，
不能当作延迟影响真值。

## Scale300 v3 产物

- 300/300 场景都有显式 v3 记录。
- 50 个授权样本已生成 T1–T4 机器候选答案。
- 为保证 T3 行动与答案对应，又新增 50 次 DeepSeek 请求；50/50 一次通过。
- 100 个源轨迹通过当前自动前置条件，但不在本次 50 条外部发送授权中，状态为待生成。
- 150 个场景因 rollout 状态、模型语义复核、版本绑定或明确结构错误被跳过。
- 50×4 共 200 个输出通过任务 schema、状态覆盖、概率和证据 ID 校验；这只是程序检查。
- 所有答案都标为 machine_proposal_pending_human_review，正式池资格为 false。

## 已知质量缺口

1. T2：50 个 DeepSeek 答案对应的是旧 v2 受控配对。答案本身通过结构检查，但配对并非
   “原轨迹 A → 改编 B → 同 ending 正式 replay”的新策略产物，因此全部只作诊断，
   formal_pool_eligible=false。
2. T3：候选行动和答案现已对齐，但未运行反事实 continuation，延迟答案不能进入正式池。
3. IA_PIPE_004：保存的机器预检已明确命中动作归属与承诺一致性失败。t1–t2 中
   environment 把对方的排班安排和个人经历改写成自己的话；v3 保留任务供诊断，但源轨迹被阻断。
4. IA_PIPE_252：Codex 定向语义抽读认为 t8–t18 持续重复“函件不到、放行/暂缓、
   责任自负”，且双方对谁决定放行出现摇摆。该判断是模型语义复核，不是人工验收。
5. 其余 48 条尚未逐条进行 Codex 完整正文复核；网站保留人工审核入口，不把结构通过写成质量通过。

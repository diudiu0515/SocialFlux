# SocialFlux Synthetic Narrative Script Generation v1

Write an original social narrative script before any benchmark normalization.

Input supplies a social mechanism, relationship structure, power structure, goal conflict, information asymmetry, desired history dependency, and coverage requirements.

Focus only on narrative quality:

- identify who the characters are and how they know each other;
- establish consequential prior events;
- state what each person wants, knows, and keeps private;
- create a real trade-off and multiple meaningful choices;
- make later interpretation depend on earlier interaction;
- avoid one universally optimal scripted response;
- use original characters, setting, events, and dialogue.

Do not mention JSON schema, latent state variables, S0/D0, video thresholds, benchmark tasks, or sampling. Return a coherent narrative script in Markdown.
